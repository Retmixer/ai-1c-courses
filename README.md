# PaceSetter School — курсы по AI и 1С

Готовый сайт для Netlify с общей базой курсов в Netlify Blobs и защищённой админ-панелью.

## Вход в админ-панель

- Логин: `Ret`
- Пароль: `4680!`
- Адрес после публикации: `https://ваш-сайт.netlify.app/#admin`

Администратор может создавать, редактировать и удалять курсы, добавлять видео с Rutube, описания уроков и домашние задания. Изменения сохраняются в общей базе и сразу видны всем посетителям.

## Публикация на Netlify

Для общей базы нужна публикация всего проекта вместе с серверными функциями. Простая загрузка только папки `dist` не подходит.

Рекомендуемый способ:

1. Загрузить всю папку `AI-1C-Courses` в GitHub-репозиторий.
2. В Netlify выбрать **Add new project → Import an existing project**.
3. Подключить репозиторий.
4. Netlify прочитает `netlify.toml`: папка публикации — `dist`, функции — `netlify/functions`.
5. Нажать **Deploy**.

После первого открытия сайта Netlify автоматически создаст хранилище Blobs и положит туда демонстрационные курсы.

## Безопасность

Логин и пароль проверяются только на сервере. В браузерном JavaScript их нет. Админская сессия хранится в защищённой HttpOnly-cookie и действует 12 часов.

Для дополнительной защиты можно создать в Netlify переменную окружения `ADMIN_SESSION_SECRET` со случайной длинной строкой. Сайт работает и без неё — в проект уже включён уникальный ключ.

## Локальный просмотр

Обычный локальный сервер показывает дизайн и демонстрационный каталог. Общая база и вход администратора начинают работать после публикации на Netlify, потому что они используют Netlify Functions и Netlify Blobs.
